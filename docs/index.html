Awesome STPA

Curated STAMP/STPA and hazard analysis resources for safety and systems engineering practitioners.

What this is

A curated, dated index of STAMP/STPA, CAST, and hazard-analysis resources: handbooks, tools, standards context, agency case studies, learning and workshops, and datasets. Every entry points at the upstream source; nothing is re-hosted. Maintained by JG Systems Consulting Ltd as part of the awesome-mbse list family.

How to use the list

  • Open the list on GitHub and browse the seven sections, or search the page in your browser.
  • Clone it: git clone https://github.com/jgsystemsconsulting/awesome-stpa.git
  • Each entry carries topic tags and a year, so you can scan for what applies to your work.

Suggest an entry or report a problem

  • Suggest a resource with the suggestion form.
  • Report a dead or wrong entry with the bug report form.
  • Security issues go through a private security advisory.
