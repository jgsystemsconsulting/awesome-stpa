§10 · Install and usage

Install and usage

Nothing to install. This list is a curated index: browse it here on GitHub, or clone it (git clone https://github.com/jgsystemsconsulting/awesome-stpa.git).

Jump to a section with the navigation above, or search the page with your browser's find function. Open any entry's link to reach the upstream resource; the list never re-hosts content. PSAS handbook and paper links keep their query strings; they are part of the address.
